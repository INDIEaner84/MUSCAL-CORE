# OC AGENT BUILD TEAM

Dieses Verzeichnis enthält die Spezifikationen und Konfigurationen aller
MUSCAL-Agenten, geordnet nach Kategorien:

- **01_Core Agents** — Zentrale System-Agenten (Memory, Testing, API, etc.)
- **02_Governance Agents** — Regelwerke, Sicherheit, Compliance, Architektur
- **03_Business Agents** — Produktisierung, Innovation, Karriere
- **04_Ops Agents** — Betrieb, Monitoring, Deployment, Kosten
- **05_Infrastructure** — Registry, Event Bus, Shared Memory, Config
- **06_Meta & System** — Architektur-Übersicht, Betriebsprotokoll, Audit, Template

Jeder Agent folgt dem MUSCAL Agent Operating Protocol (MAOP).
