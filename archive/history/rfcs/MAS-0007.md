# MAS-0007: MREIL Core Metric Engine & Evaluation Kernel

## 1. Motivation

Bis MAS-0006 existieren isolierte MREIL-Definitionen, jedoch kein zentraler Evaluationskern. Es fehlt ein System, das alle MAS-Komponenten quantitativ bewertet, Runtime-Verhalten kontinuierlich misst und Vergleichbarkeit zwischen Runs sicherstellt. Ziel: ein globales Cognitive Evaluation Subsystem (MREIL Kernel).

## 2. Terminologie

| Begriff | Definition |
|---------|-----------|
| Metric | Messbare Eigenschaft eines Runs |
| Score | Aggregierte Bewertung |
| Baseline | Referenzlauf |
| Drift | Abweichung über Zeit |
| Evaluation Frame | Einzelner Messzeitpunkt |

## 3. MREIL Core Vector

```
MREIL = (M, R, E, I, L)
```

| Dimension | Bedeutung | Formel |
|-----------|-----------|--------|
| M = Memory Retention | Kontext-Erhalt | retained_context / total_context |
| R = Reasoning Efficiency | Korrekte Schlüsse | correct_outputs / reasoning_steps |
| E = Execution Latency | Ausführungszeit | avg(node_execution_time) |
| I = Integrity Loss | Abweichung vom Referenzwert | deviation(reference, actual) |
| L = Learning Stability | Varianz über Zeit | variance(metric_over_time) |

## 4. Systemarchitektur

```
MPIR Runtime → Trace Collector → Metric Extractor → Scoring Engine → Evaluation Store
```

## 5. Scoring Function

```
MREIL_score = (w1*M + w2*R + w3*(1/E) + w4*(1-I) + w5*L)
```

Default-Gewichte: w1=0.25, w2=0.25, w3=0.2, w4=0.2, w5=0.1.

## 6. Evaluation Pipeline

```
TRACE LOG → METRIC EXTRACTION → NORMALIZATION → SCORING → STORAGE → COMPARISON (BASELINE)
```

## 7. Baseline System

- Jeder Run speichert Referenz-MREIL
- Vergleich mit vorherigen Runs
- Drift detection aktiviert bei Schwellenwert

## 8. MREIL Meta-Metrics

```yaml
mreil:
  evaluation_accuracy: "precision of metric extraction"
  drift_sensitivity: "ability to detect subtle changes"
  stability_index: "variance of scores over runs"
  benchmark_reproducibility: "cross-run consistency"
```

## 9. Fehlerfälle

| Fehler | Ursache | Reaktion |
|--------|---------|----------|
| Missing trace | Log-Lücke | Invalid evaluation |
| Corrupted metrics | Datenfehler | Score reject |
| Baseline mismatch | Drift erkannt | Drift flag |
| Inconsistent runs | Divergenz | Integrity failure |
