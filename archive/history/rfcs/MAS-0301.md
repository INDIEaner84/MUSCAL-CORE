# MAS-0301: Execution Graph Compiler

## 1. Motivation

MAS-0004 definiert den MPIR-Compiler (Prompt → AST → MPIR), aber keine formale Transformation von MCXF/YAML/MKC-Output in einen ausführbaren Execution DAG. MAS-0301 schließt diese Lücke als prä-runtime Validierungs- und Transformationsschicht.

## 2. Terminologie

| Begriff | Definition |
|---------|-----------|
| ExecNode | Atomarer Node im Execution Graph |
| ExecEdge | Gerichtete Kante zwischen Nodes |
| Execution Graph | DAG aus validierten, layer-konformen Nodes |
| MCXF | MUSCAL Context Exchange Format (Compiler-Input) |

## 3. Compiler Pipeline

```
INPUT PARSING
  MCXF / YAML / MKC → Intermediate Graph
NORMALIZATION
  Node Typisierung → Event Standardisierung → Layer Annotation
STATIC VALIDATION
  Cycle detection → Layer rule enforcement → Dependency closure check
SPINE VALIDATION
  Transition legality → Event origin verification
OPTIMIZATION
  Node fusion → Parallelization tagging → Cost estimation (MREIL)
EXECUTION GRAPH EMISSION
  DAG ready for runtime engine
```

## 5. Spine Integration

Der Compiler ruft System Spine zwingend als HARD GATE auf:

```
compile(mcxf) → parse → normalize → validate_static → spine.validate_graph → optimize → graph
```

Spine-Validierung blockiert den Compiler-Durchlauf wenn Transitionen illegal sind.

## 6. Validierungsregeln

### 6.1 Layer Rules

```
L0 → L1 → L2 → L3 → L4 → L5 → L6
```

Verboten: Überspringen von Layern, Rückwärtssprünge ohne Bridge, Events ohne Origin-Layer.

### 6.2 Dependency Rules

- Jeder Node muss erreichbar sein (keine dangling nodes)
- Zyklen verboten (Acyclicity Proof)
- Keine hidden cross-layer calls

## 7. Optimization Passes

- **Node Fusion**: Kombiniere adjacent nodes gleichen Typs
- **Parallelization Tagging**: Markiere unabhängige Subgraphen
- **Cost Estimation**: MREIL-basierte Kostenschätzung pro Node

## 9. Fehlerfälle

| Fehler | Ursache | Reaktion |
|--------|---------|----------|
| Cycle detected | Graph enthält Zyklus | Compiler error, back to input |
| Layer violation | Node überspringt Layer | Invalid graph, reject |
| Spine rejection | Illegale Transition | Block, require ADR |
| Validation failed | Regelverstoß | Error report mit Details |
