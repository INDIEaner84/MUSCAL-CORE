# MAS-0006: Capability System & Permissioned Tool Execution Layer

## 1. Motivation

Bis MAS-0005 ist Execution deterministisch, aber noch nicht sicher begrenzt hinsichtlich externer Fähigkeiten. Fehlend ist ein formales System zur Kontrolle, welche Nodes welche Aktionen (Tools, Memory Writes, IO) ausführen dürfen. MAS-0006 führt Capability-based Security, Tool Execution Gating und Sandboxed Node Permissions ein.

## 2. Terminologie

| Begriff | Definition |
|---------|-----------|
| Capability | Explizite Berechtigung für eine Operation |
| Tool | Externes oder internes ausführbares Modul |
| Permission Token | Deklarierte Fähigkeit eines Nodes |
| Sandbox | Isolierte Ausführungsumgebung |
| Guard | Validierungsinstanz vor Execution |

## 3. Capability Model

Jeder Node MUSS deklarieren:

```json
{
  "node_id": "n1",
  "capabilities": ["memory.read", "memory.write", "tool.math", "tool.search"]
}
```

## 4. Execution Gating Pipeline

```
Node Request → Capability Validator → Policy Engine → Sandbox Allocator → Execution Runtime → Result Commit
```

## 5. Policy Engine Rules

- Default deny
- Explicit allow required
- No implicit inheritance
- No capability escalation during runtime

## 6. Capability Registry

```json
{
  "tool.math":    { "description": "mathematical computation", "risk": "low" },
  "tool.search":  { "description": "information retrieval", "risk": "medium" },
  "tool.network": { "description": "external IO", "risk": "high" },
  "memory.read":  { "description": "read memory graph", "risk": "low" },
  "memory.write": { "description": "write memory graph", "risk": "medium" }
}
```

## 7. Sandbox Model

- Isolated execution context per node
- No shared memory unless explicitly granted
- IO only through capability gate
- Deterministic logging required

## 8. Security Model

- Capability must match node intent type
- Unknown capabilities → execution rejection
- Runtime cannot modify its own permissions
- All tool calls are audited

## 10. Fehlerfälle

| Fehler | Ursache | Reaktion |
|--------|---------|----------|
| Missing capability | Node deklariert nicht | Hard fail |
| Policy mismatch | Regelverstoß | Execution rejected |
| Unauthorized tool call | Sandbox-Bruch | Sandbox termination |
| Registry mismatch | Unbekannte Capability | Invalid graph |
