## Architecture

### Identity Chain

```
GovernanceStage (order=5)
  └─ generate trace_id (UUID v4) → ctx["trace_id"]
  └─ generate decision_id (UUID v4) → ctx["decision_id"]
  └─ write_decision() → decisions table
      └─ trace_id, decision_id, governance_action, decision_status
              │
              ▼
UTR.execute() (via ProvenanceContext thread-local)
  └─ read trace_id from context
  └─ generate span_id (UUID v4) per call
  └─ read decision_id from context
  └─ attach to ExecutionReceipt
```

### ProvenanceContext

Thread-local context (`features/provenance/context.py`) that propagates
provenance IDs across the pipeline without modifying immutable core files
(`kernel.py`, `mel.py`). Every pipeline stage and UTR execution on the same
thread shares the same `ProvenanceContext`.

### Authority Guarantee

- `trace_id` is SET by `GovernanceStage.process()` — the first stage in the pipeline (order=5)
- Agent code CANNOT set trace_id, span_id, or decision_id
- `UTR.execute()` reads from context — it does NOT accept provenance IDs from caller args
- All 25 adversarial tests confirm no agent-authoritative provenance

## Decisions Table Schema Upgrade

The dormant `decisions` table (schema defined in OVERRIDE-037/ADR-010) was
upgraded with 6 new columns:

| Column | Type | Description |
|--------|------|-------------|
| `trace_id` | TEXT | Trace context for the decision |
| `span_id` | TEXT | Span context for the decision |
| `decision_type` | TEXT (NOT NULL, DEFAULT 'governance') | Classification (governance, policy, etc.) |
| `decision_status` | TEXT (NOT NULL, DEFAULT 'active') | Lifecycle (active, violation, superseded) |
| `governance_action` | TEXT | Decision outcome (allow, block) |
| `parent_decision_id` | TEXT (REFERENCES decisions(id)) | Causal parent (for decision chains) |

New indexes: `idx_decisions_trace`, `idx_decisions_span`, `idx_decisions_status`.

Migration is idempotent: `_table_has_column()` check + `ALTER TABLE ADD COLUMN`
with graceful failure on existing databases.

## Provenance Binding

### ExecutionReceipt (3 new slots)
```python
trace_id: str      # UUID v4 from GovernanceStage
span_id: str       # UUID v4 from UTR.execute()
decision_id: str   # UUID v4 from GovernanceStage
```

All 3 are included in the SHA-256 integrity hash. Serialized via `to_dict()`.

### VerificationResult (1 new slot)
```python
decision_id: str   # Links verification to governance decision
```

### UTR.execute()
```python
trace_id   → read from ProvenanceContext (thread-local)
span_id    → auto-generated per execute() call
decision_id → read from ProvenanceContext
```
