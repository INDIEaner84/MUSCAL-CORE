## Known Risks

  degrades to Low confidence + warning instead of failing.
- Local Ollama is CPU-bound; synthesis = one LLM call (slow, ~1-3 min);
  agent mode requires BROWSER_INTEL_AGENT=1 and a faster LLM.
- `.venv` is new at repo root — ensure it is gitignored (check .gitignore).
- browser-use API is versioned fast (verified against 0.13.7; pin is in
  requirements.txt).
