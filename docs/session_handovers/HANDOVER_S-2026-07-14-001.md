## Change Category

**Checkpoint 0.30 — ScanContext Migration & Snapshot Integration**

Upgrades the reconciliation framework from `ScanScope`-only to a future-proof `ScanContext`-based architecture while maintaining 100% backward compatibility.

Key changes:
- **New**: `reconciliation/core/context.py` — `ScanContext` frozen dataclass holding optional `snapshot`, `scope`, and `config` placeholder
- **Modified**: `ScannerBase.scan()` now accepts `ScanContext` instead of `ScanScope`; `scan_legacy()` added for backward compat
- **Modified**: `RepositorySnapshot.to_scan_scope()` — returns `ScanScope` built from the snapshot's ignore patterns
- **Modified**: `ScanScope.from_snapshot()` — classmethod to construct scope from snapshot
- **Modified**: `ReconciliationRunner` — builds `RepositorySnapshot` once, creates `ScanContext`, passes it to scanners

No scanners, Rule Engine, or governance docs were modified.
